## Naming Convention

This repository uses the following naming style:

- Directories: `lower_snake_case`
- Source files: `lower_snake_case.cpp`
- Ordered learning sections: two-digit numeric prefixes such as `01_`, `02_`
- C++ classes: `PascalCase`
- Functions and variables: gradually standardized toward `camelCase`
